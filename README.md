# OneStop SmartCart — CEN207 Assessment 2 Prototype

## Concept
A front-end e-commerce prototype designed to reduce cart abandonment and improve purchase confidence.

## Features
1. Product catalogue
2. Product comparison
3. Guest checkout
4. Transparent subtotal, shipping and total price
5. Standard and express delivery choices
6. Estimated delivery dates
7. Multiple payment-method choices
8. Order confirmation
9. Demonstration order tracking

## Mapping to the case study
- Forced account creation -> guest checkout
- Hidden / expensive shipping costs -> transparent order summary
- Long or unclear delivery -> delivery choice + ETA
- Lack of preferred payment options -> multiple payment methods
- Product uncertainty -> product comparison
- Lack of tracking -> order tracking status

## Technology
HTML5, CSS3 and vanilla JavaScript. No backend or real payment gateway is required for this prototype.

## How to run
Open `index.html` in Chrome, Edge, Safari or another modern browser.

## Suggested 2-minute demo flow
1. Select two products and compare them.
2. Add a product to the cart.
3. Show guest checkout and transparent costs.
4. Switch Standard/Express delivery and show the ETA/cost update.
5. Select a payment method and place the demo order.
6. Show order confirmation and advance the tracking status.
